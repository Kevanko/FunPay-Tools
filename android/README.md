# FunPay Pocket для Android

Локальный клиент без VPS: вход на FunPay, список чатов, текстовые сообщения, шаблоны, поднятие выбранных категорий, приветствия и ответы по ключевым словам. Для фотографий и полной истории диалога есть переход в защищённое встроенное окно FunPay. Пароль вводится только на сайте, cookie сессии хранится через Android Keystore. Приложение не имеет JavaScript bridge для удалённых страниц.

Оформление: глина, белая, студия, терминал, бумага, лес, чернила и сланец. Профили меняют палитру, шрифт, отступы и форму панелей. Manrope с кириллицей и пять системных шрифтов работают без загрузки из сети. Доступны шесть процедурных обоев; движение можно выключить, оно также останавливается при уходе с экрана и отключается при энергосбережении. Настройки аккаунтов разделены по userId. Перенос настроек расширения — через QR или `.fpconfig` версии 1/2; cookie, товарные секреты, бонусные коды и состояние обработки в этот файл не входят.

## Работа в фоне

В «Настройки → Цвета и форма» можно изменить акцент, панели, текст и скругления. Пользовательские цвета и форма панелей применяются после переноса настроек из расширения; выбор готовой темы возвращает её стандартные значения. Цвет задаётся в формате `#RRGGBB`, а скругления `0` делают панели прямыми.

1. Войти в FunPay. Приложение распознает авторизованный аккаунт автоматически; при необходимости нажмите «Проверить вход».
2. Настроить интервал и категории поднятия, приветствие или ключевые слова.
3. Остановить автоответы этого аккаунта в расширении/VPS. Независимые устройства пока не имеют общего lock.
4. Нажать «Запустить на телефоне» и разрешить уведомления.

Сервис проверяет FunPay примерно раз в минуту с постоянным уведомлением. Поднятие выполняется с выбранным интервалом и ограничениями самого FunPay. При сетевой ошибке действует пауза; система не получает ложного подтверждения онлайна. Первая проверка запоминает существующие сообщения без ответа на старую историю. Неизвестный результат отправки виден в журнале и не повторяется вслепую.

Android 15 ограничивает `dataSync`-сервис шестью часами фонового исполнения. При системной остановке приложение завершает сервис и сообщает причину. Резервный WorkManager работает с интервалом 15 минут; Android может задержать выполнение при Doze, экономии батареи и отсутствии сети. После принудительного закрытия приложения пользователем Android не обязан запускать задачи до следующего открытия. Без VPS телефон не гарантирует непрерывный онлайн 24/7. [Ограничения Android](https://developer.android.com/develop/background-work/services/fgs/timeout).

На телефоне выполняются приветствия и ключевые слова. Автовыдача секретов, отзывы, бонусы, AI и Telegram/Discord остаются в расширении. Импорт их настроек не запускает неподдерживаемые действия. Неизвестные отправки проверяются через «Настройки → Журнал». После смены аккаунта фон остановлен; его нужно включить заново.

## Сборка

JDK 21, Android SDK с платформой 35 и build-tools 35.0.0. В Linux/macOS: `./gradlew testDebugUnitTest lintDebug assembleDebug` из этой папки. Gradle wrapper закреплён на 8.13 и проверяет SHA256 дистрибутива.

В Windows из корня проекта:

```powershell
& .\scripts\build-android.ps1 -AndroidSdk 'C:\Android\Sdk' -OutputDirectory 'C:\FunPayTools_build'
```

Скрипт собирает во внешней папке с ASCII-путём: Android Gradle Plugin не поддерживает кириллицу в пути проекта на Windows. APK отладочный, подписан debug-ключом для локальной установки. Для публикации нужен отдельный release signing key; его нельзя хранить в репозитории.

Проверки: unit tests парсеров, ошибок FunPay, шаблонов и импортируемой схемы; Android lint. UI дополнительно проверялся на эмуляторе Android 15 без реального аккаунта. Сетевые сценарии чатов и поднятия требуют проверки на тестовом аккаунте; реальные сообщения пользователя при разработке не отправлялись.

## Обновления

Приложение проверяет релиз при открытии не чаще раза в сутки; вручную — «Настройки → Проверить обновления». APK устанавливается с подтверждением Android. Релизные APK подписываются постоянным ключом вне репозитория. Отладочную сборку нужно удалить перед первой установкой релизной; дальнейшие обновления сохраняют данные.

Перед установкой проверяются SHA-256, имя пакета, более новая версия и подпись APK. После разрешения установки из FunPay Pocket вернитесь в приложение и нажмите «Установить скачанное обновление». Повторно скачивать файл не нужно.

## Первое подключение и QR

При запуске открывается отдельный экран подключения. Вход выполняется через FunPay; рабочие экраны доступны после сохранения подтверждённой сессии. Настройки можно принять до входа и применить после него.

В расширении откройте «На телефон». QR скачивания ведёт на актуальный APK. QR настроек переносит оформление и доступные параметры локально; если кодов несколько, прочитайте все. Для настроек также поддерживаются изображение QR и файл .fpconfig. Сессии, ключи аккаунтов и товарные секреты в экспорт настроек не входят.

Для входа без повторного ввода пароля откройте окно расширения через значок браузера и создайте отдельный QR входа. На телефоне выберите «Войти по QR с компьютера», отсканируйте QR и введите показанный рядом код. Сессия шифруется AES-GCM, ключ получается из случайного кода через PBKDF2-SHA256. QR действует пять минут; код хранится только в памяти окна расширения. После подтверждения приложение открывает FunPay и сверяет ID аккаунта перед сохранением сессии. Фоновая работа сама не включается.

## Синхронизация настроек

Новый QR входа также передаёт зашифрованный ключ синхронизации. Он подключается после проверки аккаунта на FunPay. Для уже подключённого телефона можно сохранить `.fptsync` в расширении и открыть его через «Настройки → Синхронизация»; аккаунты должны совпадать. Ключ хранится через Android Keystore и не попадает в обычный экспорт настроек.

Приложение проверяет изменения каждые 20 секунд, пока открыто. После местной правки оно ставит отправку в очередь; в фоне Android выполняет резервные проверки примерно раз в 15 минут и может задерживать их. Темы, фото фона и поддерживаемые настройки объединяются с учётом времени изменения каждого параметра. Видео и картинки автоответов остаются на устройстве. Синхронизация сама не запускает обслуживание FunPay.

Для обмена нужен приватный API `/v2/s/` сервера синхронизации. Его развёртывание описано в [инструкции миграции](../cloud/SECURITY.md). Старый сервер не считается пустым профилем: приложение показывает ошибку обновления сервера и сохраняет местные настройки.
