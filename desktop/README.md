# Автообновления в Chrome для Windows

Локальный компонент скачивает расширение из GitHub Releases и проверяет SHA-256. При обновлении сохраняет предыдущую версию. По умолчанию устанавливает копию в `%LOCALAPPDATA%\FunPayTools\desktop\extension`; существующую распакованную копию можно подключить по её текущему пути.

Для первой установки нужен Python 3.10 или новее. Запустите из распакованной папки:

```powershell
& .\install-updater.ps1
```

Скрипт установит текущий опубликованный релиз и зарегистрирует компонент для этой копии расширения. В `chrome://extensions` включите режим разработчика, нажмите «Загрузить распакованное расширение» и выберите напечатанный скриптом путь `extension`.

Чтобы обновлять уже установленную копию с сохранением её ID и настроек, укажите путь из страницы сведений о расширении:

```powershell
& .\install-updater.ps1 -ExtensionDirectory 'D:\FunPay-Tools-unpacked'
```

После первой установки компонента нажмите кнопку перезагрузки этой копии в `chrome://extensions`. Удалять расширение и импортировать настройки заново не нужно. Компонент принимает запросы только от ID явно подключённых папок; рабочий Git-репозиторий подключить нельзя.

Если всё же выбираете установку в новую папку, экспортируйте настройки из старой копии и импортируйте в новую. Отключите старую копию, чтобы автоматизация не запускалась дважды.

Версии с поддержкой компонента проверяют GitHub каждые шесть часов и устанавливают доступное обновление с перезапуском расширения. Кнопка «Проверить обновления» запускает ту же проверку сразу. Без компонента остаётся загрузка ZIP вручную.

При ошибке скачивания или несовпадении SHA-256 установленная версия остаётся на месте. Компонент не понижает версию и не меняет рабочие исходники.
